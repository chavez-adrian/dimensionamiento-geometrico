# Progresión bloqueada por maestría, no por tiempo

El sistema avanza al estudiante de Nivel 1 a 2, y de 2 a 3, solo cuando demuestra dominio en la Celda de Conocimiento actual — no por tiempo transcurrido ni por decisión manual. El sistema decide automáticamente; no hay override.

Se eligió este modelo porque el objetivo es Criterio de Decisión (Nivel 3), que requiere que Vocabulario y Concepto Mecánico sean prerequisitos reales, no formales. Avanzar por tiempo o por voluntad del usuario permitiría llegar a Nivel 3 sin los fundamentos necesarios, generando falsas lagunas en escenarios de troquel donde los errores tienen costo de manufactura real.

## Considered Options

- **Avance manual:** El usuario decide cuándo pasar al siguiente nivel. Descartado porque el usuario es aprendiz — no tiene criterio para saber cuándo está listo.
- **Avance por tiempo (spaced repetition puro):** El sistema programa revisiones en intervalos. Descartado porque no garantiza dominio antes de exponer conceptos dependientes.
